# SCHED-03 v3: Validate condition objects on create/update/dry-run

## Context

Review failed twice. The core issue: `AutomationRuleCreate/Update` schemas only validate that `conditions` is a JSON array — they don't validate individual condition objects. Invalid fields, operators, or age values silently fail-to-match instead of returning client-safe 4xx errors with structured `invalid_conditions` details.

## Current State

- `_validate_json_array()` (schemas.py:1331-1339) only checks `isinstance(parsed, list)`
- `evaluate_conditions()` (rules_engine.py:84-103) returns `False` for invalid conditions (silent fail)
- `test_age_condition_malformed` asserts HTTP 200 + matches=[] for value "old" (confirms the wrong behavior)
- `CONDITION_FIELDS` and `CONDITION_OPERATORS` are defined in rules_engine.py but never used for validation at create/update time

## What to Implement

### 1. Add `validate_conditions()` function to `flow_app/rules_engine.py`

```python
class ConditionError:
    """Structured error for an invalid condition object."""
    def __init__(self, index: int, field: str, message: str):
        self.index = index
        self.field = field
        self.message = message

def validate_conditions(conditions: list[dict]) -> list[ConditionError]:
    """Validate a list of condition objects against CONDITION_FIELDS and CONDITION_OPERATORS.
    Returns a list of ConditionError objects. Empty list means all conditions are valid."""
    errors = []
    for i, cond in enumerate(conditions):
        field = cond.get("field", "")
        operator = cond.get("operator", "eq")
        value = cond.get("value")

        if field not in CONDITION_FIELDS:
            errors.append(ConditionError(i, "field", f"Unknown condition field: {field!r}. Must be one of: {', '.join(sorted(CONDITION_FIELDS))}"))
            continue

        if operator not in CONDITION_OPERATORS:
            errors.append(ConditionError(i, "operator", f"Unknown operator: {operator!r}. Must be one of: {', '.join(sorted(CONDITION_OPERATORS))}"))

        # Age fields require numeric values
        if field.startswith("age_since_"):
            if value is not None:
                try:
                    float(value)
                except (TypeError, ValueError):
                    errors.append(ConditionError(i, "value", f"Age value must be a number, got {value!r}"))

    return errors
```

```python
def _validate_json_array(value: str | None, field_name: str) -> str:
    cleaned = _clean_text(value)
    try:
        parsed = json.loads(cleaned or "[]")
    except json.JSONDecodeError as exc:
        raise ValueError(f"{field_name} must be a valid JSON array.") from exc
    if not isinstance(parsed, list):
        raise ValueError(f"{field_name} must be a valid JSON array.")
    # Validate condition objects for the conditions field
    if field_name == "conditions" and parsed:
        from .rules_engine import validate_conditions
        errors = validate_conditions(parsed)
        if errors:
            details = "; ".join(f"condition {e.index}: {e.message}" for e in errors)
            raise ValueError(f"Invalid conditions: {details}")
    return cleaned or "[]"
```
