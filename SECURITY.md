# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Flow, please report it responsibly:

- **Email**: Send details to [security@axis.love](mailto:security@axis.love)
- **Do not** open a public GitHub issue for security vulnerabilities

Please include:

1. A description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if you have one)

## Response Timeline

- **Acknowledgment**: within 48 hours
- **Initial assessment**: within 5 business days
- **Fix or mitigation**: depending on severity, typically within 14 days

## Scope

This policy covers the Flow application itself (`flow_app/`). Third-party dependencies should be reported to their respective maintainers, though we appreciate being notified so we can update promptly.

## Out of Scope

- Attacks requiring physical access to the server
- Social engineering
- Denial of service
- Theoretical vulnerabilities without proof of exploit
